# 438. Find All Anagrams in a String

> 找到字符串中所有字母异位词

🔗 [LeetCode 438](https://leetcode.com/problems/find-all-anagrams-in-a-string)

---

## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的**异位词**的起始索引。

**异位词**：由相同字母重排列得到的字符串（即字母出现次数相同，顺序不同）。

### 示例

```
输入: s = "cbaebabacd", p = "abc"
输出: [0, 6]
解释:
  索引 0 → "cba" 是 "abc" 的异位词
  索引 6 → "bac" 是 "abc" 的异位词

输入: s = "abab", p = "ab"
输出: [0, 1, 2]
解释:
  索引 0 → "ab"
  索引 1 → "ba"
  索引 2 → "ab"
```

---

## 思路分析

核心思想：**定长滑动窗口 + 字符频率计数**。

- `p` 的长度固定，所以窗口大小固定为 `p.length()`
- 用**频率数组**（长度 26，因为只有小写字母）来比较窗口内字符串和 `p` 是否字母异位
- 窗口每向右滑动一步：
  - **加入**新字符（右边进入）
  - **移除**旧字符（左边离开）
  - 比较频率数组是否相同

这样不需要每次重新统计整个窗口，只需要 O(1) 更新频率。

---

## 解法：定长滑动窗口（官方简洁版）

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        int sLen = s.length(), pLen = p.length();

        if (sLen < pLen) {
            return new ArrayList<>();
        }

        List<Integer> ans = new ArrayList<>();
        int[] sCount = new int[26];
        int[] pCount = new int[26];

        // 初始化第一个窗口（前 pLen 个字符）
        for (int i = 0; i < pLen; i++) {
            ++sCount[s.charAt(i) - 'a'];
            ++pCount[p.charAt(i) - 'a'];
        }

        if (Arrays.equals(sCount, pCount)) {
            ans.add(0);
        }

        // 窗口滑动
        for (int i = 0; i < sLen - pLen; i++) {
            // 移出窗口最左边的字符
            --sCount[s.charAt(i) - 'a'];
            // 加入窗口右边的新字符
            ++sCount[s.charAt(i + pLen) - 'a'];

            if (Arrays.equals(sCount, pCount)) {
                ans.add(i + 1);
            }
        }

        return ans;
    }
}
```

### 走查：`s = "cbaebabacd", p = "abc"`

```
pCount = [a:1, b:1, c:1]

▸ 初始化第一个窗口 [0,2] = "cba"
  统计 sCount = [a:1, b:1, c:1]
  Arrays.equals → true → ans = [0]

▸ i=0: 移出 s[0]='c'，加入 s[3]='e'
  sCount: c-1=0, e+1=1 → [a:1, b:1, e:1] ≠ pCount

▸ i=1: 移出 s[1]='b'，加入 s[4]='b'
  sCount: b-1=0, b+1=1 → [a:1, b:1, e:1] ≠ pCount

▸ i=2: 移出 s[2]='a'，加入 s[5]='a'
  sCount: a-1=0, a+1=1 → [a:1, b:1, e:1] ≠ pCount

▸ i=3: 移出 s[3]='e'，加入 s[6]='b'
  sCount: e-1=0, b+1=2 → [a:1, b:2]     ≠ pCount

▸ i=4: 移出 s[4]='b'，加入 s[7]='a'
  sCount: b-1=1, a+1=2 → [a:2, b:1]     ≠ pCount

▸ i=5: 移出 s[5]='a'，加入 s[8]='c'
  sCount: a-1=1, c+1=1 → [a:1, b:1, c:1] == pCount → ans = [0, 6]

▸ i=6: 移出 s[6]='b'，加入 s[9]='d'
  sCount: b-1=0, d+1=1 → [a:1, c:1, d:1] ≠ pCount

最终 ans = [0, 6]
```

## 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | **O(n)** — n 为 `s.length()`，每个字符进出窗口一次 |
| 空间复杂度 | **O(1)** — 两个固定长度 26 的数组 |

---

## 关键点总结

- ✅ **定长窗口**：窗口大小固定为 `p.length()`，不需动态调整
- ✅ **频率数组**：用 `int[26]` 比 `HashMap` 更高效，因为只有小写字母
- ✅ **`ch - 'a'`** 技巧：将字符映射到 `0~25` 的索引
- ✅ **`Arrays.equals()`**：直接比较两个数组是否相等，简洁高效

  - **3 题**是**变长窗口**：找最长无重复子串
