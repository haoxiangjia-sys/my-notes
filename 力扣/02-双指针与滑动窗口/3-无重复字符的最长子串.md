# 3. Longest Substring Without Repeating Characters

> 无重复字符的最长子串

🔗 [LeetCode 3](https://leetcode.com/problems/longest-substring-without-repeating-characters)

---

## 题目描述

给定一个字符串 `s`，找出其中不含重复字符的**最长子串**的长度。

### 示例

```
输入: s = "abcabcbb"
输出: 3
解释: "abc", "bca", "cab" 都是正确答案

输入: s = "bbbbb"
输出: 1
解释: "b"

输入: s = "pwwkew"
输出: 3
解释: "wke"（注意："pwke" 是子序列，不是子串）
```

---

## 思路分析

核心思想：**滑动窗口 + 哈希表**。

- 用两个指针 `left` 和 `right` 维护一个窗口
- `right` 每次向右走一步，将字符加入窗口
- 如果遇到重复字符（窗口中已有），则移动 `left` 直到重复字符被移除
- 每次更新最大窗口长度

关键点：用哈希表记录字符最近一次出现的索引，这样 `left` 可以直接跳到重复字符的下一个位置，而不需要一步步挪。

### 图解：两种解法的区别

```
解法一（HashMap 存索引）：
  left 一步跳到位：
  {a:0, b:1, c:2}  遇到 a → left = 0+1 = 1  ✅ 一步到位

解法二（HashSet）：
  left 一步步挪：
  {a, b, c}  遇到 a → 移除 a(left=1) → 移除 b(left=2) → 移除 c(left=3)
                       然后才把 a 加进去                ❌ 三步
```

---

## 解法一：滑动窗口（哈希表存索引 ✅ 最优）

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> charIndex = new HashMap<>();
        int left = 0, maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            char ch = s.charAt(right);
            // 如果 ch 在窗口内出现过，移动 left
            if (charIndex.containsKey(ch) && charIndex.get(ch) >= left) {
                left = charIndex.get(ch) + 1;
            }
            charIndex.put(ch, right);
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

### 示例走查：`s = "abcabcbb"`

| right | ch | left | char_index | window | max_len |
|-------|----|------|------------|--------|---------|
| 0 | a | 0 | {a:0} | a | 1 |
| 1 | b | 0 | {a:0, b:1} | ab | 2 |
| 2 | c | 0 | {a:0, b:1, c:2} | abc | 3 |
| 3 | a | 1 | ... | bca | 3 |
| 4 | b | 2 | ... | cab | 3 |
| 5 | c | 3 | ... | abc | 3 |
| 6 | b | 5 | ... | cb | 3 |
| 7 | b | 7 | ... | b | 3 |

## 解法二：滑动窗口（哈希集合版）

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> chars = new HashSet<>();
        int left = 0, maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            char ch = s.charAt(right);
            while (chars.contains(ch)) {
                chars.remove(s.charAt(left));
                left++;
            }
            chars.add(ch);
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```

**区别**：用 set 的话 left 只能一步步挪（`while` 循环），不如解法一的直接跳转高效，但更容易理解。

## 复杂度分析

| 维度 | 值 |
|------|-----|
| 时间复杂度 | **O(n)** — 每个字符最多被访问两次（一进一出） |
| 空间复杂度 | **O(min(m, n))** — m 为字符集大小（ASCII 128 / Unicode），n 为字符串长度 |

## 关键点总结

- ✅ 滑动窗口 + 哈希表是"无重复子串"类题目的**标准解法**
- ✅ 哈希表存**索引**比存布尔值更优：left 可以直接跳，不需要 while 循环
- ✅ 窗口定义是 `[left, right]` 闭区间，长度为 `right - left + 1`
- ❌ 「子串(substring)」必须是连续的，不要和「子序列(subsequence)」搞混
