# Linux 管道、搜索与文本处理

## 一、管道 `|` — 命令的组合

管道把**左边命令的输出**传给**右边命令**：

```bash
ls -la | wc -l          # 当前目录有多少条目（包括隐藏的）
cat file.txt | grep "error"     # 在文件内容中搜 "error"
ps aux | grep node              # 找 node 相关进程
history | tail -20              # 看最近 20 条命令
```

---

## 二、`grep` — 文本搜索

```bash
grep "关键词" file.txt                # 在文件中搜
grep -i "error" log.txt              # 忽略大小写
grep -r "TODO" src/                  # 递归搜整个目录
grep -n "function" app.js            # 显示行号
grep -v "debug" log.txt              # 排除含 debug 的行
grep -c "error" log.txt              # 统计匹配行数
grep -A 3 "error" log.txt            # 显示匹配行及后面 3 行
grep -B 2 "error" log.txt            # 显示匹配行及前面 2 行
grep -C 5 "error" log.txt            # 显示匹配行及前后各 5 行
```

实用组合：
```bash
# 找所有 .md 文件中含 "TODO" 的
grep -r "TODO" --include="*.md" .

# 排除 node_modules 的搜索
grep -r "import" --exclude-dir=node_modules .

# 从上一个命令的输出中过滤
npm list | grep "react"
```

## 三、`find` — 文件查找

```bash
find . -name "*.js"                  # 按名字找当前目录及子目录下所有 .js
find . -type f -name "*.md"          # 只找文件（排除目录）
find . -type d -name "test"          # 只找目录
find . -mtime -7                     # 7 天内修改过的文件
find . -size +10M                    # 大于 10MB 的文件
find . -name "*.log" -delete         # 找到并删除所有 .log 文件（⚠️）
```

## 四、重定向 `>` `>>` `<`

```bash
ls > files.txt                # 输出写到文件（覆盖）
ls >> files.txt               # 输出追加到文件（不覆盖）
sort < unsorted.txt           # 把文件内容喂给命令
ls 2> errors.txt              # 错误信息写到文件
ls > all.txt 2>&1             # 标准输出和错误都写到一个文件
```

## 五、其他实用命令

```bash
sort file.txt                          # 按行排序
sort -r file.txt                       # 倒序
sort -u file.txt                       # 去重排序
uniq file.txt                          # 去重（需先 sort）
cut -d',' -f1 data.csv                 # 按逗号分隔取第一列
wc -l file.txt                         # 统计行数
du -sh *                               # 每个文件/目录的大小
df -h                                  # 磁盘使用情况
free -h                                # 内存使用情况
top                                    # 实时进程（q 退出）
htop                                   # top 的升级版（需安装）
history                                # 命令历史
!123                                   # 重新执行历史中第 123 条
Ctrl+R                                 # 反向搜索历史命令（超好用！）
```

## 实操练习 🎯

```bash
cd ~
mkdir pipe-practice
cd pipe-practice

# 1. 创建一些数据
echo "apple" > fruits.txt
echo "banana" >> fruits.txt
echo "Apple pie" >> fruits.txt
echo "cherry" >> fruits.txt
echo "banana bread" >> fruits.txt

# 2. grep 练习
grep "apple" fruits.txt         # 只匹配小写
grep -i "apple" fruits.txt      # 忽略大小写，两条都匹配

# 3. 管道练习
cat fruits.txt | sort            # 排序输出
cat fruits.txt | sort | uniq     # 去重
cat fruits.txt | grep "banana" | wc -l   # 统计 banana 出现次数

# 4. 创建嵌套文件测试 find
mkdir -p sub1/sub2
touch sub1/a.js sub1/b.txt sub1/sub2/c.js

find . -name "*.js"             # 找到所有 .js
find . -type f | wc -l          # 统计总文件数

# 5. 清理
cd ..
rm -rf pipe-practice
```
