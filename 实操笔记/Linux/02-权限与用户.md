# Linux 权限与用户

## 一、看懂 `ls -l` 的输出

```bash
ls -l
# -rwxr-xr--  1 xiang users  4096 Jun 10 14:30 hello.txt
#  ├──权限──┤  │ 用户  组  │ 大小  日期   时间    文件名
#             └─硬链接数─┘
```

权限分成三组，每组三个字母：

```
-   rwx   r-x   r--
│    │     │     │
│    │     │     └─ 其他人（other）权限
│    │     └─────── 同组用户（group）权限
│    └───────────── 所有者（owner）权限
└────────────────── 文件类型（-文件 d目录 l链接）
```

| 字母 | 含义 | 数字 |
|------|------|------|
| `r` | 读取 read | 4 |
| `w` | 写入 write | 2 |
| `x` | 执行 execute | 1 |

## 二、修改权限 `chmod`

### 数字方式（常用）
```bash
chmod 755 script.sh    # rwxr-xr-x   （所有者全权，其他人读+执行）
chmod 644 file.txt     # rw-r--r--   （所有者读写，其他人只读）
chmod 777 file.txt     # rwxrwxrwx   （❌所有人全权，不安全！）
chmod 600 secret.key   # rw-------   （只有你能读写）
```

### 字母方式
```bash
chmod +x script.sh     # 加执行权限
chmod -w file.txt      # 去掉写权限
chmod u+x script.sh    # 只给所有者加执行
chmod g-w file.txt     # 去掉组的写权限
```

## 三、`sudo` 的正确用法

```bash
# sudo = 临时以 root 身份执行一条命令
sudo apt update              # 更新软件源
sudo apt install git         # 安装软件
sudo nano /etc/hosts         # 编辑系统文件
```

> ⚠️ **不要** `su root` 然后一直用 root 操作，太危险。**永远用 sudo**。

## 四、用户相关命令

```bash
whoami                      # 我是谁？
id                          # 查看自己的 uid、gid、所属组
passwd                      # 修改自己的密码
sudo passwd root            # 给 root 设置密码（一般不需要）
```

## 实操练习 🎯

```bash
# 1. 创建一个脚本文件
cd ~
echo '#!/bin/bash' > test.sh
echo 'echo "脚本运行成功!"' >> test.sh

# 2. 查看权限
ls -l test.sh
# 应该没有 x（执行权限）

# 3. 尝试运行
./test.sh
# 会报错 Permission denied

# 4. 加执行权限
chmod +x test.sh
ls -l test.sh   # 看到 x 了

# 5. 再次运行
./test.sh
# 成功！

# 6. 清理
rm test.sh
```
