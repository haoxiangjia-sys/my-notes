## 三、技术架构全景图

金风科技的技术路线是 **"风机硬件 × 数字软件"** 深度融合。

### 3.1 智能风机三层架构

| 层级 | 核心能力 | 关键技术 |
|------|---------|---------|
| **深度感知层** | 提前感知来流、环境状态 | 激光雷达、卫星导航、状态传感器 |
| **自我认知与控制层** | 自适应调节，降载增发 | 载荷降低 5%~10%，发电优化 |
| **协同决策层** | 场群 → 能源互联网协同 | 单场协同 → 场群协同 → 全网协同 |

### 3.2 核心数字平台 — Goldwind DEEP™

基于 **155GW+ 清洁能源资产数据** 构建的能源物联网平台：

```
数字连接能源 ──→ 数字洞见能源 ──→ 数字赋能能源
（采集与治理）     （计算与分析）     （大数据应用）
```

典型应用：
- **SOAM 智慧运营**：无人化场站，巡检效率提升 5.4 倍
- **AI 功率预测**：气象大模型，空间分辨率达 100 米级
- **金风天机交易云**：电力交易数字化，覆盖 28 省 19GW 资产

- 熟悉 Spring Boot / Spring Cloud / MyBatis
- 熟悉 MySQL，具备 SQL 优化能力
- 熟悉 Redis、消息队列等中间件
- 熟悉 Linux 基本操作

**加分项：**
- 物联网（IoT）开发经验
- Docker / Kubernetes 容器化经验
- 有时序数据库（InfluxDB）使用经验
- 了解 MQTT 协议
- 分布式、高并发系统设计经验
