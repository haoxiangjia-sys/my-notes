## 课程总览 Overview

**这门课在讲什么？What is this course about?**

Bridging the gap between **high-level programming languages** and the **hardware** that executes them — understanding the full abstraction layer from software to hardware:

```
Java/Python 代码 High-level code
      ↓
    编译器 Compiler
      ↓
    汇编指令 Assembly
      ↓
    机器码 Machine code
      ↓
CPU 执行 Execution（Datapath + Control）
      ↓
   逻辑门 Logic Gates（AND/OR/NOT）
      ↓
   晶体管 Transistors（Switches）
```

## 三大核心主题 Three Core Themes

### 1️⃣ 从数学到数字逻辑 From Math to Digital Logic（W1）
Boolean algebra → Logic gates → Combinational logic → Sequential logic

### 2️⃣ 从数字逻辑到处理器 From Logic to Processor（W2-W4）
Von Neumann architecture → Instruction set → ALU → Datapath → Control unit

### 3️⃣ 从处理器到软件 From Processor to Software（W5-W6）
Memory hierarchy → Cache → Assembly → Linking → Interrupts
