## 1. 布尔代数基础 Boolean Algebra

### 基本运算 Basic Operations

| 运算 Operation | 符号 Symbol | 说明 Description | 口诀 |
|:--------------|:------------|:-----------------|:-----|
| AND 与 | `A · B` 或 `A ∧ B` | 全1为1 / Outputs 1 only if both are 1 | 有0出0 |
| OR 或 | `A + B` 或 `A ∨ B` | 有1为1 / Outputs 1 if at least one is 1 | 有1出1 |
| NOT 非 | `¬A` 或 `A'` | 取反 / Inverts the input | 0变1，1变0 |
| NAND 与非 | `A ↑ B` | AND后取反 / NOT(AND) | 有0出1 |
| NOR 或非 | `A ↓ B` | OR后取反 / NOT(OR) | 有1出0 |
| XOR 异或 | `A ⊕ B` | 不同为1 / Outputs 1 if inputs differ | 相同0，不同1 |

### 常用定律 Common Laws
- **交换律 Commutative**：A · B = B · A
- **结合律 Associative**：(A · B) · C = A · (B · C)
- **分配律 Distributive**：A · (B + C) = A · B + A · C
- **德摩根定律 De Morgan's Laws**：`¬(A · B) = ¬A + ¬B`，`¬(A + B) = ¬A · ¬B`

## 2. 二进制与补码 Binary & Two's Complement

### 进制转换 Number Base Conversion
- **二进制 Binary → 十进制 Decimal**：按权展开 / Multiply each bit by its place value
- **十进制 Decimal → 二进制 Binary**：除2取余 / Repeatedly divide by 2
- **十六进制 Hexadecimal**：每4位二进制转1位十六进制 / 4 binary bits → 1 hex digit

### 补码 Two's Complement
- 正数的原码 = 补码 = 反码
- 负数的补码 = 原码取反 + 1 / Invert all bits then add 1
- **为什么用补码 Why use two's complement?**：统一加减法，CPU不用设计减法器 / Unified addition & subtraction — no separate subtractor circuit needed

## 3. 组合逻辑 Combinational Logic

**特点 Characteristic**：输出只取决于当前输入，无记忆 / Output depends only on current inputs, no memory

| 元件 Component | 功能 Function |
|:--------------|:--------------|
| 半加器 Half Adder | 两个bit相加，输出和+进位 / Adds 2 bits, outputs sum + carry |
| 全加器 Full Adder | 三个bit相加（含进位输入）/ Adds 3 bits (including carry-in) |
| 多路选择器 MUX | 选择多路输入中的一路输出 / Selects one of multiple inputs |
| 译码器 Decoder | 将n位输入转为2ⁿ位输出 / Converts n-bit input to 2ⁿ-bit output |

---

## 4. 时序逻辑 Sequential Logic

**特点 Characteristic**：输出取决于当前输入 + 历史状态（有记忆）/ Output depends on current inputs AND past state (has memory)

| 元件 Component | 功能 Function |
|:--------------|:--------------|
| SR锁存器 SR Latch | 最基本的1bit存储单元 / Basic 1-bit storage element |
| D触发器 D Flip-flop | 时钟上升沿锁存数据 / Captures data on rising clock edge |
| 寄存器 Register | 多个D触发器组合 / Group of D flip-flops |

### 组合 vs 时序 Comparison
```
组合逻辑 Combinational：            时序逻辑 Sequential：
输入 Input → 门 Gates → 输出 Output   输入 → 门 → 输出
                                        ↑         ↓
                                      时钟 CLK  存储器 Memory
```
