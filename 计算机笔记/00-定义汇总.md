## W1 — 数字逻辑 Digital Logic

### 命题 Proposition
> A proposition is a statement whose meaning can be evaluated to yield a truth value (false or true), must be unambiguous, can include free variables, and can be represented using a short-hand variable or function.

**命题**是一个陈述句，其含义可以判断真假值，必须无歧义，可包含自由变量，可用变量或函数简写表示。

### 连接词 Connectives

| English | 中文 | 正式名 | 规则 |
|:--------|:-----|:-------|:-----|
| `¬x` | NOT 非 | Logical Negation 逻辑否定 | 取反 |
| `x ∧ y` | AND 与 | Logical Conjunction 逻辑合取 | 全真为真 |
| `x ∨ y` | OR 或 | Logical (Inclusive) Disjunction 逻辑析取 | 有真为真 |
| `x ⊕ y` | XOR 异或 | Logical (Exclusive) Disjunction | 一真一假为真 |
| `x → y` | IMPLY 蕴含 | Logical Implication | 仅真→假为假 |
| `x ↔ y` | EQUIV 等价 | Logical Equivalence | 同真同假为真 |

### 布尔代数公理 Boolean Algebra Axioms

| 公理 Axiom | AND 版 | OR 版 |
|:-----------|:-------|:------|
| Commutativity 交换律 | `x·y = y·x` | `x+y = y+x` |
| Association 结合律 | `(x·y)·z = x·(y·z)` | `(x+y)+z = x+(y+z)` |
| Distribution 分配律 | `x·(y+z) = x·y + x·z` | `x+(y·z) = (x+y)·(x+z)` |
| Identity 恒等律 | `x·1 = x` | `x+0 = x` |
| Null 零律 | `x·0 = 0` | `x+1 = 1` |
| Idempotency 幂等律 | `x·x = x` | `x+x = x` |
| Inverse 逆律 | `x·x̄ = 0` | `x+x̄ = 1` |
| Absorption 吸收律 | `x+x·y = x` | `x·(x+y) = x` |
| De Morgan 德摩根 | `x̄·ȳ = ¬(x+y)` | `x̄+ȳ = ¬(x·y)` |

### 范式 Standard Forms

> **Sum of Products (SoP)** / 析取范式 (Disjunctive Normal Form): an expression written as a sum (OR) of terms which each comprise the product (AND) of variables. Each term is called a **minterm**.
> **Product of Sums (PoS)** / 合取范式 (Conjunctive Normal Form): an expression written as a product (AND) of terms which each comprise the sum (OR) of variables. Each term is called a **maxterm**.

**SoP（析取范式）**：用 OR 把 AND 项连起来，每项叫 minterm。
**PoS（合取范式）**：用 AND 把 OR 项连起来，每项叫 maxterm。

## W2 — 进制与算术 Number Systems & Arithmetic

### 大小端 Endianness

> **Little-endian**: read bits from right-to-left — LSB is right-most, MSB is left-most.
> **Big-endian**: read bits from left-to-right — LSB is left-most, MSB is right-most.

**小端（Little-endian）**：从右往左读，最低有效位在最右边。
**大端（Big-endian）**：从左往右读，最低有效位在最左边。

### 汉明重量 Hamming Weight
> The Hamming weight of X, denoted HW(X), is the number of bits in X that are equal to 1.

**汉明重量**：位序列 X 中值为 1 的位的个数。

### 汉明距离 Hamming Distance
> The Hamming distance between X and Y, denoted HD(X, Y), is the number of bits in X that differ from the corresponding bit in Y.

**汉明距离**：X 和 Y 中对应位不同的个数。

### 无符号整数 Unsigned Integer
> An unsigned integer is represented using the natural binary expansion: each bit weighted by 2ⁱ. Range: 0 ≤ x ≤ 2ⁿ − 1.

**无符号整数**用自然二进制展开表示，每位权重为 2ⁱ。范围：0 到 2ⁿ−1。

### 有符号整数（补码）Signed Integer (Two's Complement)
> A signed integer using two's complement: the MSB is weighted by −2ⁿ⁻¹ instead of +2ⁿ⁻¹. Range: −2ⁿ⁻¹ ≤ x ≤ 2ⁿ⁻¹ − 1.

**有符号补码**：最高位权重是 −2ⁿ⁻¹ 而不是 +2ⁿ⁻¹。范围：−2ⁿ⁻¹ 到 2ⁿ⁻¹−1。

### 有符号整数（原码）Signed Integer (Sign-Magnitude)
> 1 bit for sign (0=positive, 1=negative), n−1 bits for magnitude. Two zeros (+0 and −0). Range: −2ⁿ⁻¹+1 ≤ x ≤ 2ⁿ⁻¹−1.

**有符号原码**：1 位符号 + n−1 位数值。有两个零（+0 和 −0）。范围：−2ⁿ⁻¹+1 到 2ⁿ⁻¹−1。

## W3 — 晶体管与逻辑门 Transistors & Gates

### N-MOSFET
> An N-MOSFET (N-type MOSFET) is constructed from N-type semiconductor terminals and a P-type body. Applying a potential difference to the gate widens the channel, allowing current to flow.

**N-MOSFET（N 型场效应管）**：由 N 型半导体端子和 P 型衬底构成。给栅极加电压 → 沟道变宽 → 导通。

### 传播延迟 Propagation Delay
> Within combinational logic, two classes of delay dictate the time between change to some input and corresponding change in an output:
> - **Wire delay** 线延迟: time for current to move through conductive wire.
> - **Gate delay** 门延迟: time for transistors in each gate to switch.

**线延迟（Wire delay）**：电流通过导线的时间。
**门延迟（Gate delay）**：门内晶体管开关的时间。

### 关键路径 Critical Path
> The critical path through combinational logic is the longest sequential path between an input and output, i.e., the path with the largest total delay.

**关键路径**：组合逻辑中从输入到输出延迟最大的那条路径。决定了电路的最小时钟周期。

### 扇入 / 扇出 Fan-in / Fan-out
> **Fan-in**: the number of inputs to a given gate.
> **Fan-out**: the number of inputs (other gates) the output of a given gate is connected to.

**扇入（Fan-in）**：一个门有多少个输入端。
**扇出（Fan-out）**：一个门的输出连接了多少个其他门的输入。

## W3~4 — 组合/时序器件 Combinational & Sequential Components

### 分解器 Demultiplexer
> A demultiplexer routes a single input to one of 2ⁿ outputs, selected by n select lines.

**分解器（Demultiplexer）**：1 入 → 2ⁿ 出。n 根选择线选一路输出。和 MUX 方向相反。

### 全加器 Full Adder
> A full adder component adds three 1-bit inputs (A, B, C_in) to produce a sum and carry-out.

**全加器（Full Adder）**：3 个 1-bit 输入（A, B, 进位入）→ Sum + 进位出。

### 双稳态 Bistable
> A bistable component can exist in two stable states (0 or 1). At a given point it can **retain** some current state Q (read as output), and be **updated** to some next state Q′ under control of an enable signal en.

**双稳态器件**：能稳定存在两种状态（0 或 1）。可保持当前状态 Q，也可在使能信号控制下更新到下一个状态。

### 锁存器 vs 触发器 Latch vs Flip-flop
> A bistable controlled by an enable signal can be:
> - **Level-triggered** (电平触发): updated by a given **level** on en → termed a **latch**.
> - **Edge-triggered** (边沿触发): updated by a given **edge** on en → termed a **flip-flop**.

**锁存器（Latch）**：电平触发 → 使能信号为高/低期间可更新。
**触发器（Flip-flop）**：边沿触发 → 只在上升沿/下降沿瞬间更新。

### SR 锁存器/触发器
> Two inputs S (set) and R (reset). When enabled:
> - S=0, R=0 → retain Q
> - S=1, R=0 → Q = 1
> - S=0, R=1 → Q = 0
> - S=1, R=1 → **meta-stable** (invalid)

**SR**：S=Set（置 1），R=Reset（置 0）。S=R=1 禁止。

### D 锁存器/触发器
> One input D. When enabled:
> - D=1 → Q = 1
> - D=0 → Q = 0

**D**：Data。来什么存什么，最简单的存储单元。

### JK 锁存器/触发器
> Two inputs J and K. When enabled:
> - J=0, K=0 → retain Q
> - J=1, K=0 → Q = 1
> - J=0, K=1 → Q = 0
> - J=1, K=1 → **toggle** Q (翻转)

**JK**：解决了 SR 的 J=K=1 无效问题 → J=K=1 时翻转。

### T 锁存器/触发器
> One input T. When enabled:
> - T=0 → retain Q
> - T=1 → **toggle** Q (翻转)

**T（Toggle）**：T=1 翻转，T=0 保持。最简单的计数器元件。

## W5 — 硬件描述语言 HDL

### HDL (Hardware Description Language)
> A Hardware Description Language (HDL) is used to describe (or model) hardware (e.g., digital logic). In contrast to a conventional programming language which is typically used to describe software. Examples: Verilog, VHDL, MyHDL, Chisel.

**硬件描述语言**：用于描述/建模硬件（如数字逻辑），而不是软件。代表：Verilog、VHDL。

## W8 — 有限状态机 Finite State Machines

### 字母表 Alphabet
> An alphabet Σ is a non-empty set of symbols.

**字母表 Σ**：一个非空的符号集合。如 {0, 1} 或 {a, b, c}。

### 字符串 String
> A string X with respect to some alphabet Σ is a sequence, of finite length, whose elements are members of Σ. If length is zero, it's the **empty string** (denoted ε).

**字符串**：由字母表中符号构成的有限长序列。长度为 0 时称为空串 ε。

### 语言 Language
> A language L is a set of strings.

**语言 L**：一组字符串的集合。

### 有限状态机 FSM
> A (deterministic) Finite State Machine (FSM) is a tuple C = (S, s₀, Σ, Λ, δ, ω) — an idealised computer which at a given point in time is in one of some finite set of states. It accepts an input string one symbol at a time; each symbol potentially induces a change in state.

**有限状态机（FSM）**：一个理想化计算模型 C = (状态集, 初态, 输入字母表, 输出字母表, 状态转移函数, 输出函数)。每次读一个符号，根据当前状态和输入决定下一状态。

## W10 — 指令集架构 ISA

### 指令 Instruction
> An instruction is a description of a computational step.

**指令**：对一个计算步骤的描述。

### 寄存器机 Register Machine (RM)
> A Register Machine (RM) is specified by a set of registers, a memory, and an instruction set. Modern CPUs are register machines.

**寄存器机（RM）**：由寄存器组、存储器和指令集组成。现代 CPU 都是寄存器机。

### 存储程序概念 Stored Program Concept
> The stored program concept implies that a mutable program is stored in some form of memory; a stored program computer is one whereby instructions in such a program are loaded (or fetched) from memory before execution.

**存储程序概念**：程序存放在存储器中，指令在执行前从内存取出。这是冯·诺依曼架构的核心思想。

### 程序计数器 Program Counter (PC)
> The Program Counter (PC) is a special-purpose register that holds the address of the next instruction to be executed.

**程序计数器（PC）**：存放下一条要执行指令的地址。

### 指令寄存器 Instruction Register (IR)
> The Instruction Register (IR) is a special-purpose register that holds the instruction currently being executed.

**指令寄存器（IR）**：存放当前正在执行的指令。

### 取指-译码-执行周期 Fetch-Decode-Execute Cycle
> The fetch-decode-execute cycle (aka. instruction cycle) is a 3-stage process:
> 1. **Fetch**: load instruction from memory at address PC, increment PC.
> 2. **Decode**: interpret the instruction (opcode + operands).
> 3. **Execute**: perform the operation.

**取指-译码-执行周期**（指令周期）三阶段：
1. **Fetch 取指**：从 PC 指向的内存地址取指令，PC 自增
2. **Decode 译码**：解析操作码和操作数
3. **Execute 执行**：完成运算

## W11 — 存储器 Memory

### 存储墙 Memory Wall
> The term **memory wall** refers to a gap between efficiency of instruction execution and memory access. If memory access latency and bandwidth are insufficient, the associated micro-processor may wait (i.e., becomes idle) until instructions and/or data are delivered.

**存储墙**：指令执行速度和内存访问速度之间的巨大差距。CPU 越来越快，内存跟不上 → CPU 等内存。

### 冯·诺依曼瓶颈 Von Neumann Bottleneck
> The **von Neumann bottleneck** is a criticism of the stored-program concept: the shared bus between CPU and unified memory means instruction fetch and data access compete for the same bandwidth.

**冯·诺依曼瓶颈**：指令和数据共用一条总线 → 取指令和取数据不能同时进行 → 瓶颈。

## W14 — 寻址方式 Addressing Modes

### 寻址方式 Addressing Mode
> An addressing mode specifies how an instruction interprets its operands — i.e., where the data is: in the instruction itself (immediate), in a register (register direct), in memory (direct/indirect/indexed/...).

**寻址方式**：指令如何定位操作数。立即数（值在指令里）、寄存器直接（值在寄存器里）、直接（值是内存地址）、间接（寄存器存指针）等。

### 编码压力 Encoding Pressure
> The limited number of bits in an instruction for opcode and operand creates encoding pressure — the challenge of fitting all desired instructions and addressing capabilities within the fixed-width encoding.

**编码压力**：指令中 opcode 和 operand 只能占有限位，要在固定位宽里塞下所有指令和寻址能力。
