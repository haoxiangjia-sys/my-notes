## 1. 指令格式 Instruction Format

一条机器指令通常包含 A machine instruction typically contains：

```
┌────────────┬──────────────┬──────────────┐
│  操作码     │  目标操作数   │  源操作数     │
│  Opcode    │  Destination │  Source      │
│  (e.g. ADD)│  (rd)        │  (rs/imm)    │
└────────────┴──────────────┴──────────────┘
```

### 寻址模式 Addressing Modes

| 模式 Mode | 例子 Example | 说明 Description |
|:----------|:-------------|:----------------|
| **立即数 Immediate** | `ADDI R1, 5` | 操作数在指令中 / Operand in instruction |
| **寄存器 Register** | `ADD R1, R2` | 操作数在寄存器 / Operand in register |
| **直接 Direct** | `LW R1, 100` | 内存地址在指令 / Memory address in instruction |
| **寄存器间接 Register Indirect** | `LW R1, (R2)` | 内存地址在寄存器 / Address in register |
| **基址偏移 Base+Offset** | `LW R1, 8(R2)` | R2+8 得到地址 / R2 + offset = address |

## 2. 指令分类 Instruction Categories

### 数据传送 Data Transfer
| 指令 | 功能 Function |
|:----|:--------------|
| `LW rt, offset(rs)` | 从内存加载到寄存器 / Load word from memory to register |
| `SW rt, offset(rs)` | 从寄存器存到内存 / Store word from register to memory |
| `MOV rd, rs` | 寄存器间复制 / Copy between registers |

### 算术运算 Arithmetic
| 指令 | 功能 Function |
|:----|:--------------|
| `ADD rd, rs, rt` | rd = rs + rt |
| `SUB rd, rs, rt` | rd = rs - rt |
| `ADDI rd, rs, imm` | rd = rs + immediate |
| `MUL rd, rs, rt` | rd = rs × rt |
| `DIV rd, rs, rt` | rd = rs ÷ rt |

### 逻辑运算 Logical
| 指令 | 功能 Function |
|:----|:--------------|
| `AND rd, rs, rt` | 按位与 Bitwise AND |
| `OR rd, rs, rt` | 按位或 Bitwise OR |
| `XOR rd, rs, rt` | 按位异或 Bitwise XOR |
| `SLL rd, rs, shamt` | 左移 Shift Left Logical |

### 控制转移 Control Transfer
| 指令 | 功能 Function |
|:----|:--------------|
| `BEQ rs, rt, label` | 相等则跳转 / Branch if Equal |
| `BNE rs, rt, label` | 不等则跳转 / Branch if Not Equal |
| `J label` | 无条件跳转 / Unconditional Jump |
| `JAL label` | 跳转并保存返回地址 / Jump And Link (save return address) |

## 3. 指令执行过程 Instruction Execution

```
取指 Fetch ──► 译码 Decode ──► 执行 Execute ──► 访存 Mem ──► 写回 Writeback
    ↑                                                         │
    └───────────────── 下一条指令 Next Instruction ────────────┘
```

### 每条指令经过的步骤 Step-by-step
```
ADD R1, R2, R3:
  ① Fetch: PC → Instruction memory → get instruction
  ② Decode: Identify ADD, read R2, R3
  ③ Execute: ALU computes R2 + R3
  ④ Memory: （不需要访存 / Not needed）
  ⑤ Writeback: Write result to R1, PC+4

LW R1, 8(R2):
  ① Fetch
  ② Decode: Identify LW, read R2
  ③ Execute: ALU computes R2 + 8
  ④ Memory: Use ALU result as address, read data memory
  ⑤ Writeback: Write data to R1, PC+4

BEQ R1, R2, label:
  ① Fetch
  ② Decode, read R1, R2
  ③ Execute: ALU compares R1 == R2
  ④ If equal: PC = label; else PC+4
```

## 4. MIPS/RISC-V 汇编示例 Assembly Examples

```assembly
# 计算数组元素之和 Sum array elements: sum = arr[0] + arr[1]
# 假设 arr 地址在 R1，结果存 R3

LW    R2, 0(R1)      # R2 = arr[0]  (load first element)
LW    R4, 4(R1)      # R4 = arr[1]  (load second element)
ADD   R3, R2, R4     # R3 = R2 + R4 (sum)

# 条件分支 Conditional branch
ADDI  R5, R0, 10     # R5 = 10
BEQ   R3, R5, done   # if R3 == 10 goto done
ADDI  R3, R3, 1      # R3 = R3 + 1  (increment)
done:
```
