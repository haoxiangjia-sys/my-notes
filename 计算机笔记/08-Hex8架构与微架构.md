## 1. Hex 8 架构概述

**Hex 8** 是本课程自制的教学用 8 位计算机架构，用于理解 CPU 内部工作原理。

### 基本规格

| 特性 | 值 |
|:-----|:----|
| **字长 Word size** | 8 位（1 字节）|
| **地址空间 Address space** | 8 位 → 256 字节（$2^8$）|
| **通用寄存器 GPRs** | 2 个：R0（累加器）、R1 |
| **指令长度** | 8 位定长（RISC 风格）|
| **指令数量** | 16 条（4 位 opcode）|
| **内存** | 256 字节，统一编址（冯·诺依曼）|

### Hex 8 指令集

```
Opcode  Mnemonic  描述                       操作
──────  ────────  ─────────────────────────  ─────────────────
0000    HLT       停机 Halt                  停止执行
0001    LDA addr  加载 Load                   R0 = M[addr]
0010    STA addr  存储 Store                  M[addr] = R0
0011    ADD addr  加法 Add                    R0 = R0 + M[addr]
0100    SUB addr  减法 Subtract               R0 = R0 - M[addr]
0101    JMP addr  跳转 Jump                   PC = addr
0110    JGE addr  大于等于跳转 Jump if ≥      if R0 ≥ 0: PC = addr
0111    JNZ addr  非零跳转 Jump if ≠ 0        if R0 ≠ 0: PC = addr
1000    INP port  输入 Input                  R0 = I[port]
1001    OUT port  输出 Output                 O[port] = R0
1010    LDI imm   立即数加载 Load Immediate   R0 = imm
1011    ADI imm   立即数加法 Add Immediate    R0 = R0 + imm
1100    INC       自增 Increment              R0 = R0 + 1
1101    DEC       自减 Decrement              R0 = R0 - 1
1110    SHL       左移 Shift Left             R0 = R0 << 1
1111    SHR       右移 Shift Right            R0 = R0 >> 1
```

### 指令格式 Instruction Format

```
8 位指令：
┌────────┬────────────┐
│ Opcode │  Operand   │
│  4位   │   4位      │
└────────┴────────────┘

例：LDA R1  →  0001 0001
    LDI 5   →  1010 0101
    ADD R1  →  0011 0001
```

> ⚠️ operand 只有 4 位，所以：
> - 立即数范围：0-15（4 位无符号）
> - 地址范围：0-15（只能访问前 16 字节！）
> - 要访问更高地址需要**间接寻址**或**变址**（见 W14）

## 2. 架构 vs 微架构 Architecture vs Micro-architecture

### 关键区别

| 概念 | 定义 | 类比 |
|:-----|:-----|:------|
| **ISA（指令集架构）** | 程序员可见的接口：指令集、寄存器、内存模型 | 汽车的"操作方式"（方向盘、油门、刹车）|
| **微架构** | 具体实现方式：数据通路、控制单元、流水线结构 | 汽车的"内部机械"（发动机、传动轴怎么连）|

### 同一个 ISA，不同微架构

```
ISA 相同（如 x86）但微架构不同：
┌──────────────────────────────────────────┐
│  Intel Core i7  vs  Intel Pentium        │
│  都是 x86 ISA（运行同一份机器码）        │
│  但内部微架构完全不同：流水线级数、       │
│  Cache 大小、分支预测器⋯⋯                │
└──────────────────────────────────────────┘
```

### Hex 8 的 ISA vs 微架构

| 层面 | 内容 |
|:-----|:-----|
| **Hex 8 ISA** | 上面那张指令表 + 寄存器 R0/R1 + 256 字节内存 |
| **Hex 8 微架构** | 你在 ModuleSim 里搭的具体电路（数据通路、控制单元、ALU、寄存器文件⋯⋯）|

## 4. ModuleSim 实现要点

在 ModuleSim 中实现 Hex 8 需要：

1. **程序计数器 PC**：8 位寄存器，存当前指令地址
2. **指令存储器**：256×8 位 ROM/RAM
3. **寄存器文件**：2 个 8 位寄存器（R0, R1）
4. **ALU**：实现加减、移位、比较
5. **控制单元**：根据 opcode 生成控制信号
6. **数据存储器**：256×8 位 RAM

### 取指-译码-执行（Hex 8 版）

```
① 取指：IR = M[PC];  PC = PC + 1
② 译码：控制单元解析 opcode[7:4] 和 operand[3:0]
③ 执行：根据控制信号操作 ALU / 寄存器 / 内存
④ （重复）
```

> **Lab 资源**：W13-W17 的 ModuleSim 实验一步步搭建了完整的 Hex 8 计算机。
> - W13 Lab: 基础模块（寄存器、ALU）
> - W14 Lab: 程序计数器 + 指令存储器
> - W15 Lab: 控制单元 + 数据存储器

### 📝 常见考题形式

**题型1：指令识别**
```
题目：十六进制 0xA5 是什么 Hex 8 指令？
解法：
  0xA5 = 1010 0101
  opcode[7:4] = 1010 = LDI（Load Immediate）
  operand[3:0] = 0101 = 5
  答案：LDI #5（R0 = 5）
```

**题型2：写 Hex 8 汇编**
```
题目：用 Hex 8 汇编实现 R0 = R0 + 5

答案：
  ADI #5    ; R0 = R0 + 5
  （一条指令搞定！）
```

**题型3：微架构图**
```
题目：画出 Hex 8 的微架构框图，标出 PC、指令存储器、ALU、寄存器文件

解法：默写上面第 3 节的图
```

### ⚠️ 易错点
- **operand 只有 4 位** → 直接寻址只能访问 0-15，不是 0-255！
- **LDI 是立即数**，**LDA 是从内存加载** — 不要搞混
- **JGE 和 JNZ** 的区别：JGE 检查 Negative 标志，JNZ 检查 Zero 标志
- **INC/DEC 不需要 operand**（因为操作对象固定是 R0）
