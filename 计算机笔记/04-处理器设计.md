## 1. ALU（算术逻辑单元 Arithmetic Logic Unit）

ALU 是 CPU 的"计算引擎" / ALU is the computing engine of the CPU：

```
       ┌──────┐
  A ──►│      │
       │ ALU │────► 结果 Result
  B ──►│      │
       └──┬───┘
          │
       控制信号 Control Signal
       (选哪种运算 Selects operation)
```

### ALU 支持的典型操作 Typical Operations

| 控制信号 Control | 操作 Operation | 功能 Function |
|:---------------:|:--------------|:--------------|
| 0000 | AND | A & B |
| 0001 | OR | A \| B |
| 0010 | ADD | A + B |
| 0110 | SUB | A - B |
| 0111 | SLT (Set Less Than) | A < B 置1 / Sets 1 if A < B |

## 2. 单周期 CPU 数据通路 Single-Cycle Datapath

### 核心部件 Core Components

| 部件 Component | 功能 Function |
|:--------------|:--------------|
| **PC**（程序计数器 Program Counter） | 存当前指令地址 / Holds current instruction address |
| **指令存储器 Instruction Memory** | 存指令代码 / Stores instructions |
| **寄存器堆 Register File** | 32个通用寄存器 / 32 general-purpose registers |
| **ALU** | 算术逻辑计算 / Arithmetic & logic operations |
| **数据存储器 Data Memory** | 存数据 / Stores data |
| **控制单元 Control Unit** | 译码生成控制信号 / Decodes instructions, generates control signals |

### 数据通路图 Datapath Diagram（Core Structure）

```
                    ┌─────────────┐
  PC ────► 指令存储器 │             │
           Instruction│  控制单元   │───► Control signals
           Memory    │  Control    │     (RegWrite, ALUSrc,
                    │  Unit       │      MemWrite, etc.)
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │   寄存器堆   │
  ┌────────────────►│  Register   │
  │                 │  File       │
  │                 └──────┬──────┘
  │                        │
  │                   ┌────▼────┐
  │                   │   ALU   │
  │                   └────┬────┘
  │                        │
  │                   ┌────▼────┐
  │                   │ 数据存储器│
  │                   │  Data    │
  │                   │  Memory │
  │                   └────┬────┘
  │                        │
  └────────────────────────┘
```

### 取指→译码→执行循环 Fetch-Decode-Execute Cycle

```
① 取指 Fetch
   PC → 指令存储器 Instruction Memory → get instruction
   同时 PC = PC + 4（准备下一条 / Prepare next instruction）

② 译码 Decode
   从指令中提取 opcode, rs, rt, rd, imm / Extract fields
   控制单元根据 opcode 生成控制信号 / Control unit generates signals
   读寄存器堆，取出 rs 和 rt 的值 / Read register values

③ 执行 Execute
   ALU 计算结果 / ALU computes result
   如果是分支指令，在这里判断是否跳转 / Branch condition checked

④ 访存 Memory
   如果是 LW：从数据存储器读数据 / Read from data memory
   如果是 SW：把数据写入数据存储器 / Write to data memory
   其他指令：这步不做任何事 / Others: nothing

⑤ 写回 Writeback
   把结果写回寄存器堆的 rd / Write result back to register
```

### 微编码控制 vs 硬连线控制 Microprogrammed vs Hardwired Control

| 对比 Comparison | 微编码 Microprogrammed | 硬连线 Hardwired |
|:---------------|:----------------------|:-----------------|
| **实现方式 Implementation** | 用ROM存微指令序列 / ROM stores micro-instructions | 组合逻辑电路直接译码 / Combinational logic |
| **速度 Speed** | 慢（读ROM有延迟 / ROM access delay） | 快 Fast |
| **灵活性 Flexibility** | 容易修改（改ROM就行 / Easy to modify） | 改了就重做芯片 / Requires chip redesign |
| **复杂指令 Complex instr.** | 适合CISC | 适合RISC |
| **代表 Examples** | 老x86CPU Older x86 | ARM、RISC-V、现代CPU |
